# grain-guard

Прогноз самосогревания зерна за **72 часа**: физическая модель + ML, MVP для мониторинга реального объекта.

**Режим работы: только реальные данные.** Синтетика удалена из продукта (пакет `synth` остаётся исключительно генератором тестовых фикстур); `benchmark` принимает только `--source` CSV реального объекта.

**Цель MVP:** доказать на одном объекте, что система предупреждает о самосогревании
раньше оператора и предотвращает измеримый ущерб (тонны / рубли).

Полный план и критерии приёмки: [TASKS.md](TASKS.md). Статус — ниже.

## Статус по этапам (проверено [TASKS.md], синтетика n=1000, seed=42, VPS)

| Этап | Статус | Ключевые метрики |

| 2. Физика | частично | критические кривые из CGC + ASABE D535 с источниками ([docs/sources.md](docs/sources.md)) ✓; recall **0.81** (нужно ≥0.9), lead 141 ч ✓, FP 0.24 ✓; нет тестов энергобаланса |

## Быстрый старт

```bash
uv sync                 # + uv sync --extra service, если нужен HTTP-сервис моделей
uv run pytest           # 18 тестов (фикстуры генерируются локально, только для тестов)
uv run grain-guard benchmark --source <csv реального объекта> --config configs/pilot.yaml
```

Тяжёлые прогоны — на VPS через HTTP-сервис моделей: [docs/remote-api.md](docs/remote-api.md).

## Источники данных и параметров

Все параметры моделей ссылаются на первоисточники (CGC Safe Storage Guidelines,
ASABE D535 / Steele–Saul–Hukill, NDSU) либо помечены «подобрано на синтетике»:
**[docs/sources.md](docs/sources.md)** — URL, что именно взято, дата доступа.
Поиск реальных данных показал: открытой телеметрии хранения с инцидентами
самосогревания не существует.

## Постановка задачи

По телеметрии силоса (6 слоёв датчиков T, влажность, T воздуха, тип зерна) предсказать
начало самосогревания за 72 часа до фактического развития очага и раньше типового
оператора (тревога при T зерна выше фиксированного порога 32 °C).

## Схема данных

| Столбец | Описание |
|---|---|
| `silo_id`, `timestamp` | силос, время (шаг 1 ч) |
| `T_layer_1..6` | температура зерна по слоям датчиков, °C |
| `T_air`, `W_moisture` | T воздуха, °C; влажность зерна, % |
| `grain_type` | wheat / barley / corn |
| `storage_day` | сутки хранения |
| `incident`, `incident_start`, `operator_detect` | разметка: флаг, начало инцидента, момент обнаружения оператором (порог 32 °C) |

## Структура каталогов

## CLI

```bash
grain-guard benchmark --source data/raw/<объект>.csv --config configs/pilot.yaml --out reports
grain-guard ingest --source data/raw/<объект>.csv --config configs/pilot.yaml --out data/processed/clean.csv
grain-guard serve --host 127.0.0.1 --port 8000              # HTTP-сервис моделей (VPS)
```
